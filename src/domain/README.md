# domain 層

このアプリケーションが何であるかを表現する層。**このリポジトリで最も価値のあるコード**を置く。

## 置くもの

- 値オブジェクト (`TaskId`, `TaskName`, `TaskFilter`)
- エンティティ (`Task`)
- ファーストクラスコレクション (`TaskList`)
- リポジトリの**インターフェース** (`TaskRepository`)
- ドメインサービス、ドメインイベント

## 依存してよいもの

**何にも依存しない。** React にも、nanoid にも、localStorage にも、他のどの層にも。

ここに `import` 文がほとんど無いことが、ドメインモデルが独立している証拠になる。
外の世界が必要になったら、それは「このドメインが何を必要としているか」を
インターフェースとして domain 層に定義し、実装は infrastructure 層に置く（依存性逆転）。

## 判断の目安

「このアプリが React ではなく CLI だったとしても、このコードは同じか？」
同じなら domain 層に属する。
