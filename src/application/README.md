# application 層

ユースケースを表現する層。**ドメインオブジェクトを組み合わせて、ひとつの操作を完結させる**。

## 置くもの

- ユースケース (`AddTask`, `RenameTask`, `ToggleTaskCompletion`, `DeleteTask`, `ListTasks`)
- UI に渡す DTO とその組み立て

## 依存してよいもの

domain 層のみ。infrastructure 層の具体的な実装には依存せず、
domain 層が定義したリポジトリインターフェース越しに永続化を扱う。

## 判断の目安

ここには**ビジネスルールを書かない**。ルールは domain 層にある。
この層がやるのは「リポジトリから取り出す → ドメインオブジェクトに仕事をさせる → 保存する」
という手順の調整だけ。ここにルールが書かれ始めたら、それは domain 層から漏れ出したサイン。
